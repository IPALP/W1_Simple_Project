The project consists of an Unity game about an car that crashes into different objects, some add points to the score some take away points, and the booster multiplies the score by 2. The player is under the pressure of time, and has to get as many points as it can.
I started with the player controller, which the user can control both with wasd and the arrows, then I added an box generator, that places boxes at random positions, and coded them to dissapear on contact with the player. Next I have worked on the UI elements, such as the restart screen, the timer and the score counter, after this I have implemented a few other obstacles aside from the boxes, which deal differnet amount of damage to your score, and also added the 2x boost, which doubles your score.
I provided an itch.io link with an web build of the project which showcases the main features of my project so far. I have developed my project on an MacOS device. This is my first Unity project, so there may be some rough edges. I'm still learning, and if anything in these instructions doesn't work, please let me know and I'll fix it. Thank you for checking it out!
